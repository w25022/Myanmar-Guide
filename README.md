# 🇲🇲 Myanmar Guide

A modern, responsive travel and culture website introducing Myanmar's famous destinations, traditional cuisine, outdoor adventures, and rich cultural heritage. Designed for foreign tourists, international visitors, and student portfolio showcases.

---

## 🌟 Technologies Used

- **HTML5** — Semantic, accessible page layout and structure
- **CSS3** — Custom styling, CSS custom properties (variables), Flexbox, CSS Grid, and Dark/Light mode transitions
- **Vanilla JavaScript (ES6+)** — Dynamic card generation, instant search filtering, reusable modal system, interactive SVG map, clipboard API integration, and currency converter calculations

> **Note:** Built strictly using pure HTML, CSS, and Vanilla JavaScript with zero external frameworks or build tooling dependencies.

---

## ✨ Features & Architecture

- **Interactive Myanmar SVG Map:** Clickable states/regions and destination pins that dynamically update a rich regional information card with photos, highlights, and climate descriptions.
- **Famous Places (12 Major Destinations):** Instant search and category filtering (`Historical`, `Nature`, `Beach`, `Culture`, `City`, `Religious`) with detailed pop-up modals.
- **Myanmar Traditional Food (12 Authentic Dishes):** Filterable by food type (`Noodles`, `Salad`, `Rice`, `Snack`, `Dessert`, `Curry`) and searchable by dish name or ingredient, with spice-level badges and dining culture context.
- **Adventure Experiences:** Featured expedition guide for **🏔️ Hkakabo Razi Trekking** with difficulty ratings and crucial mountaineering safety notices, plus additional adventures across Hpa-An, Inle Lake, Mergui Archipelago, and Shan Hills.
- **Culture & People:** Respectful, educational explorations of Kayan traditions, Chin highland culture, traditional ceremonial Khauk Ye rice wine, the rhythmic Bamboo Dance, Longyi & Thanaka, and Myanmar marionette puppetry.
- **Useful Myanmar Language Phrasebook:** Essential everyday travel phrases with Burmese script, phonetics, and a one-click **Copy Script** button with visual feedback.
- **Live Currency Converter:** Instant conversion between Myanmar Kyat (MMK), USD, JPY, EUR, THB, and SGD with quick currency swap and clear reference disclaimers.
- **Practical Travel Tips:** Comprehensive advice on weather seasons, temple etiquette, dress codes, cash handling, transportation, and respectful cultural practices.
- **Dark / Light Theme Engine:** Smooth theme toggle stored in browser `localStorage` for persistent visitor preferences.
- **Mobile-First Responsive Design:** Fully responsive layout with sticky navigation and a smooth collapsible hamburger menu on mobile devices.

## 🚀 How to Run & Deploy

### 1. Run Locally

Simply open `index.html` in any modern web browser (Chrome, Firefox, Safari, Edge). No build step, package manager, or server installation required!

### 2. GitHub Pages

1. Push the repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Source**, select `main` branch and `/ (root)` folder.
4. Click **Save**. The website will be live in seconds.

### 3. Vercel

1. Import your GitHub repository into Vercel.
2. Keep the default static settings (Framework Preset: **Other**, Build Command: empty).
3. Click **Deploy**.
